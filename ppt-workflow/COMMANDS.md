# PPT Workflow 指令集

## 通用调用

```text
使用 $ppt-workflow 处理这个 PPT 任务。先判断任务类型，只读取必要规则，完成后逐页渲染检查。
```

## 新建 PPT

```text
使用 $ppt-workflow 制作一份可编辑的 PPTX。根据我的材料组织内容，不虚构数据或项目成果，完成后运行完整质量检查。
```

## 新建城乡规划或学术汇报

```text
使用 $ppt-workflow 制作一份城乡规划学术汇报 PPT。加载规划学术规范和基础排版规范，保持专业、简洁、高信息密度，完成后逐页检查。
```

## 修改已有 PPT

```text
使用 $ppt-workflow 修改当前最新 PPT。先备份源文件，只修改我明确授权的部分；文字、布局、图片、页数、页面顺序和动画默认保持不变。
```

## 只换视觉风格

```text
使用 $ppt-workflow 只调整这份 PPT 的视觉风格。禁止修改文字、字体、字号、布局、图片、页数和顺序；修改前后比较结构并输出新文件。
```

## 极简蓝白风格

```text
使用 $ppt-workflow 将当前 PPT 调整为白底、蓝色细线、黑灰文字的极简学术风格。只换皮肤，不改内容和骨架。
```

## 传统蓝色卡

```text
使用 $ppt-workflow 和传统蓝色卡处理当前 PPT。默认采用 Palette A｜规划灰蓝，保持白底，只做颜色映射，不修改内容、布局、图片和动画。
```

## 清爽传统蓝

```text
使用 $ppt-workflow 的传统蓝色卡，选择 Palette B｜清雅青蓝。保证标题投影可读，浅色只用于小面积辅助。
```

## 正式传统蓝

```text
使用 $ppt-workflow 的传统蓝色卡，选择 Palette C｜深黛蓝。保持白底，深蓝只作少量强调，不做黑蓝商务风。
```

## 质量检查

```text
使用 $ppt-workflow 检查这份 PPT 的文字溢出、重叠、越界、字体、页码、图片裁剪、配色一致性、可编辑性和文件完整性。先报告问题，不要擅自修改未授权内容。
```

## 继续上次工作

```text
使用 $ppt-workflow 继续上次 PPT 工作。读取项目目录中最新文件和已有续接文档，先确认源文件，再从未完成步骤继续，不要重新制作。
```

## 更新 Skill

```text
使用 Skill Creator 更新我的 $ppt-workflow，把这次确认的新规则加入对应文件，保持按需加载，并重新运行 skill 验证。
```
