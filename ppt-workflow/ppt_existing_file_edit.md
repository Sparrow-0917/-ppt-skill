# Existing PPT Edit

## 默认保护范围

当前 PPT 的内容和结构默认已由用户确认。未获明确授权时，不得：

- 修改任何文字、标题、数据或备注。
- 增删、合并、拆分页或改变页面顺序。
- 替换、删除、裁剪、移动或缩放图片。
- 重新布局文本框、图表、表格、流程图和其他对象。
- 改变字体、字号、行距、动画、母版或页面尺寸。

只修改用户明确点名的属性。视觉修改和内容修改必须分开处理。

## 安全流程

1. 按修改时间识别用户指定目录中的当前版本，并向用户说明选中的源文件。
2. 修改前复制独立备份，绝不覆盖唯一原件。
3. 渲染源文件全部页面，记录页数、尺寸、版式和特殊对象。
4. 选择最能保留源结构的工具，编辑复制件或私有候选文件。
5. 输出为新的、含义清楚的文件名。
6. 修改后比较页数、尺寸、文字、对象位置、图片裁剪和动画元数据。
7. 渲染最终文件并逐页与源文件对照。

## 仅换风格时

用户只要求换风格或配色时，仅调整：

- 页面背景
- 填充颜色
- 文字颜色
- 边框和线条颜色
- 阴影、渐变、发光和 3D 效果
- 不承载信息的装饰元素

不要借机重写内容、移动元素或重新设计页面。

## 冲突处理

当“统一背景”与“必须保留现有图片”等要求冲突时，优先保留用户明确要求保护的对象；说明该对象仍可见的原因，不擅自删除或覆盖。

Windows + PowerPoint 环境下，可使用 `scripts/ppt_guard_snapshot.ps1` 在修改前后生成结构快照并比较关键不变量。
