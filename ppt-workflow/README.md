# Personal PPT Workflow

这是用户个人 PowerPoint 工作流技能库，适用于城乡规划、国土空间规划、建筑、城市设计、GIS、专业实习、课程汇报、会议及一般学术演示。

## 执行顺序

```text
读取 QUICK_START
↓
读取 SKILL_INDEX
↓
判断新建、编辑、换风格或检查
↓
加载 2–5 个相关文件
↓
读取当前 PPT 或资料
↓
执行并保留可编辑性
↓
运行质量检查
↓
输出新文件
```

## 快速调用

可直接说：

> 读取我的 PPT skills，然后修改这份 PPT。只改我明确指定的内容。

也可以显式调用：

> 使用 `$ppt-workflow` 制作一份城乡规划学术汇报 PPT。

## 目录说明

- `SKILL.md`：Codex 可发现的入口和路由。
- `QUICK_START.md`：最短初始化说明。
- `SKILL_INDEX.md`：按任务选择文件。
- `COMMANDS.md`：可直接复制使用的调用指令集。
- `ppt_*.md`：各类工作规范。
- `ppt_color_palettes.md`：实测传统蓝色卡和候选色板。
- `scripts/`：可重复执行的保护性检查脚本。
- `references/`：环境与实现参考。
- `external_skills/`：经审查后才加入的外部资源。
