# PPT Base

## 开始前

- 明确输出格式、页面数量、比例、汇报时长、受众和语言。
- 新建演示文稿通常采用 16:9；存在模板或源文件时必须保持原尺寸。
- 先确认字体在当前环境可用。中文优先使用用户指定字体；没有指定时选择稳定的中文字体，并保持全文一致。

## 排版原则

- 标题、正文、注释形成清楚层级；相同层级保持字号、颜色和位置一致。
- 使用统一页边距、列线和对齐基准。优先边缘对齐、中心线对齐和等距分布。
- 留白用于分组，不用无意义装饰填满空白。
- 单页只保留支撑本页主题的信息。内容多时先提炼和图形化，不直接缩成不可读的小字。
- 页码、章节编号和分隔线应统一且不抢夺内容层级。

## 图像、表格和图表

- 图片保持比例，不拉伸；证据性图片不得裁掉关键区域。
- 不伪造项目成果。缺少真实图片时使用明确占位框。
- 表格优先保持原生可编辑。表头、正文、边框和对齐保持一致。
- 图表必须保留数据含义、单位、图例和来源；不要用装饰替代数据证据。
- 流程图、关系图和表格在用户要求可编辑时使用原生对象。

## 可编辑与兼容

- 不把整页栅格化。
- 文字、表格、图表和必要图形保持可编辑。
- 现有 PPT 中的动画、母版、图片裁剪、备注和嵌入对象默认保留。
- 输出到新文件，不覆盖唯一原件。

## 输出前

- 检查文字溢出、元素重叠、对象越界、图片失真和异常裁切。
- 检查字体替换、标题一致性、页码和页面顺序。
- 渲染全部页面并逐页查看，再执行 `ppt_quality_check.md`。
